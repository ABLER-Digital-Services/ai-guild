# システム関連図

## 概要

〇〇システムと連携する外部システムとのデータの流れを示す。

## 図

→ [01_システム関連図.drawio](./01_システム関連図.drawio)

## 連携システム一覧

| システム名 | 区分 | 連携方向 | 主なデータ |
|---|---|---|---|
| （例）マスタ管理システム | 社内システム | 受信 | 顧客データ、商品データ |
| （例）受注管理システム | 社内システム | 受信 | 注文データ |
| （例）ECサイト | 社内システム | 受信 | 注文データ |
| （例）請求書作成システム | 社内システム | 送信 | 請求データ |
| （例）会計システム | 社内システム | 送信 | 仕訳データ（売上・入金） |
| （例）○○銀行 | 外部サービス | 受信 | 銀行入金データ |
| （例）○○決済代行会社 | 外部サービス | 受信 | クレジット決済データ |
