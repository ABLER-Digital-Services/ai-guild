# システム関連図スキル

開発対象システムを中心に据え、連携する外部システム・周辺システムとの関係およびデータの流れを draw.io で可視化する。

## When to Use This Skill

- 「システム関連図を作って」「システム間の関係を整理して」と言われたとき
- 開発スコープ（自システムの境界）を明確にしたいとき
- 外部システムとのインタフェース概要を視覚的に示したいとき
- 既存のシステム関連図をレビュー・更新するとき

## 成果物の仕様


## 図のレイアウト規約

| 要素 | 表現方法 |
|---|---|
| **開発対象システム（自システム）** | 中央配置・青背景・サブ機能を内部に列挙 |
| **外部システム・周辺システム** | グレー背景・サブ機能を内部に列挙（必要な場合） |
| **銀行・決済など外部サービス** | グレー背景・シンプルなボックス（内部詳細なし）|
| **データの流れ（矢印）** | 矢印にデータ種別のラベルを付ける |
| **双方向連携** | 双方向矢印または2本の矢印で方向を明示 |

### カラールール

| 色 | 用途 |
|---|---|
| 青（`#dae8fc` / `#6c8ebf`） | 開発対象システム（自システム） |
| グレー（`#f5f5f5` / `#666666`） | 外部システム・連携先 |

## 作成ワークフロー

### Step 1: 対象システムと連携先の確認

ユーザーに以下を確認する：

1. **開発対象システム名**: 中心に置くシステム名
2. **主要サブ機能**: 自システム内の主要な機能モジュール（3〜8個程度）
3. **連携する外部システム**: 名称・方向（送信/受信/双方向）・データ種別
4. **配置の方向感**: どのシステムを上/下/左/右に置くか（任意）

### Step 2: draw.io ファイルの生成

draw.io MCP (`mcp_drawio_open_drawio_xml`) を使い、`templates/system-context-diagram-template.drawio` をベースにシステム名・機능名・矢印ラベルを実際の内容に差し替えて生成する。

### Step 3: Markdownラッパーの作成

`templates/system-context-diagram-template.md` を元にMarkdownを作成する。

### Step 4: レビューチェック

- [ ] 開発対象システムが中央に配置されているか
- [ ] すべての連携先システムが網羅されているか
- [ ] 矢印にデータ種別のラベルが付いているか
- [ ] データの流れ方向（送信/受信）が正しいか
- [ ] インタフェース一覧（`06_インタフェース一覧`）との整合性が取れているか
