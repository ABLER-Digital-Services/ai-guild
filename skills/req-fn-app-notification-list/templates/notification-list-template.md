# 通知一覧

## ユーザー向け通知

| 宛先 | 契機 | 通知内容 |
|---|---|---|
| （例）新規登録ユーザー | 会員登録完了時 | 登録完了のお知らせと初回ログインURL案内 |
| （例）メールアドレス変更をしたユーザー | メールアドレス変更申請時 | 変更確認URLの案内（本人確認） |
| （例）パスワードリセットを申請したユーザー | パスワードリセット申請時 | パスワード再設定URLの案内 |
| （例）パスワードを変更したユーザー | パスワード変更完了時 | パスワード変更完了のお知らせ |
| （例）注文を確定したユーザー | 注文確定時 | 注文内容・注文番号・配送予定の案内 |
| （例）注文がキャンセルされたユーザー | 注文キャンセル時 | キャンセル完了と返金手続きの案内 |
| （例）長期未ログインのユーザー | 最終ログインから〇〇日経過時 | サービス継続利用の案内 |

## 管理者・運営向け通知

| 宛先 | 契機 | 通知内容 |
|---|---|---|
| （例）システム管理者 | バッチ処理エラー発生時 | エラー発生バッチ名・エラー内容・発生時刻 |
| （例）システム管理者 | 新規会員登録時 | 新規登録会員の情報（氏名・メールアドレス・登録日時） |
| （例）店舗管理者 | 自店舗に新規注文が入った時 | 注文者・注文内容・配送先の案内 |
| （例）店舗管理者 | 在庫が閾値を下回った時 | 対象商品名・現在在庫数の案内 |
