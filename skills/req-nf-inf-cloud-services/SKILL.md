# クラウドサービス設計書スキル

AWSを利用するシステムの基盤設計として、利用するAWSサービスとリソース構成を定義するドキュメントを作成・更新する。
設計方針・AWSアカウント設計・利用サービスの概要・本システムにおける用途を網羅する。

## When to Use This Skill

- 「クラウドサービス設計書を作って」「基盤概要設計_クラウドサービス編を作って」と言われたとき
- 「クラウドサービスを整理して」「AWSサービスを定義して」「利用リソースを整理して」と言われたとき
- 既存のクラウドサービス設計書をレビュー・更新するとき

## 作成ワークフロー

### Step 1: テンプレートをコピーして成果物を作成

例として、`templates/基盤概要設計_クラウドサービス編_template.md` を
`docs/01_要件定義/02_非機能/03_クラウドサービス/基盤概要設計_クラウドサービス編.md` にコピーして作業を開始する。

既存ファイルがある場合は上書きせず、差分を確認してから追記・修正する。

### Step 2: ユーザーへのヒアリング

以下の観点でシステムの構成を確認する：

**設計方針**
- マルチアカウント構成か、シングルアカウント構成か
- 環境分離の方針（本番・ステージング・開発をAWSアカウントで分けるか、VPCで分けるか）
- クラウドサービスの命名規則（タグ戦略など）
- コスト管理の方針（AWS Budgets、Cost Allocationタグなど）

**AWSアカウント設計**
- 利用するAWSアカウントの数と役割（管理アカウント、本番アカウント等）
- AWS Organizationsの利用有無
- IAM Identity Centerの利用有無

**利用サービス・リソース**
- ネットワーク: VPC構成（サブネット数、AZ数、パブリック/プライベート分離）
- コンピューティング: EC2かECS/Fargateかサーバレス（Lambda）か
- データベース: RDSのエンジン種別（MySQL/PostgreSQL等）・Aurora・DynamoDB等
- ストレージ: S3のバケット用途（アプリデータ・ログ・バックアップ等）
- CDN/ルーティング: CloudFront・Route 53の要否
- セキュリティ: WAF・Shield・GuardDuty・Secrets Manager等の利用有無
- 監視: CloudWatch（メトリクス・ログ・アラーム）の利用範囲
- メール送信: SESの要否
- キュー/メッセージング: SQS・SNSの要否
- コンテナレジストリ: ECRの要否

### Step 3: 各サービスセクションへの記述

ヒアリング結果を元に、利用するAWSサービスについて以下のフォーマットで記述する。

```markdown
### Amazon ○○
Amazon ○○は＜サービスの一般的な説明＞。

#### ＜リソース名＞
**概要**: ＜そのリソースの一般的な概要＞
**用途**: ＜本システムにおける用途・設定内容＞
```

- 利用しないサービスのセクションはテンプレートから削除する
- 用途欄には「本システムでは～」を明示し、具体的な設定値（CIDRブロック・インスタンスタイプ・ストレージサイズ等）も記載する

### Step 4: レビューチェック

- [ ] `設計方針` に環境分離・命名規則・コスト管理方針が記述されているか
- [ ] `AWSアカウント設計` にアカウント構成と役割が記述されているか
- [ ] 利用するAWSサービスのサービスセクションがすべて存在するか
- [ ] 各リソースの **用途** 欄が「＜本システムにおける用途＞」のままになっていないか
- [ ] システム構成図（`02_システム構成/`）と利用サービス・リソースが整合しているか
- [ ] セキュリティ関連サービス（WAF・Secrets Manager・GuardDuty等）の記載が、セキュリティ要件と整合しているか

## テンプレートの構成

テンプレート（`templates/基盤概要設計_クラウドサービス編_template.md`）は以下のセクションで構成される：

| セクション | 内容 |
|---|---|
| 設計方針 | アカウント戦略・環境分離方針・命名規則・コスト管理 |
| AWSアカウント設計 | アカウント一覧・役割・Organizations構成 |
| 利用サービス、リソース | 各AWSサービスのリソース定義 |
| └ Amazon VPC | VPC・サブネット・IGW・NATゲートウェイ・セキュリティグループ |
| └ Amazon EC2 / Auto Scaling | EC2インスタンス・AMI・起動テンプレート・ALB |
| └ Amazon ECS / Fargate | クラスター・タスク定義・サービス |
| └ Amazon RDS | DBインスタンス・サブネットグループ・パラメータグループ |
| └ Amazon S3 | バケット（用途別） |
| └ Amazon CloudFront | ディストリビューション・オリジン・キャッシュポリシー |
| └ Amazon Route 53 | ホストゾーン・レコードセット |
| └ AWS WAF | WebACL・ルールグループ |
| └ AWS IAM | ロール・ポリシー・インスタンスプロファイル |
| └ AWS Secrets Manager | シークレット管理 |
| └ Amazon CloudWatch | メトリクス・ロググループ・アラーム |
| └ Amazon SES | 送信ドメイン・送信設定セット |
| └ Amazon SQS | キュー（用途別） |
| └ Amazon ECR | リポジトリ |
| └ AWS Backup | バックアッププラン・ボールト |
