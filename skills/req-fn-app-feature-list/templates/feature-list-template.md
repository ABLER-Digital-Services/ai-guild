# 機能一覧

## オンライン機能

| 機能ID | 機能名 | 概要 | アクター | 備考 |
|---|---|---|---|---|
| F-O-001 | （例）ログイン画面 | システムへのログイン認証 | 一般会員／店舗管理者／システム管理者 | |
| F-O-002 | （例）会員一覧画面 | 登録済み会員の検索・一覧表示 | システム管理者 | |
| F-O-003 | （例）会員登録画面 | 新規会員情報の入力・登録 | 一般会員 | 会員登録フローから遷移 |
| F-O-004 | （例）会員編集画面 | 既存会員情報の編集・更新 | 一般会員／システム管理者 | |
| F-O-005 | （例）商品一覧画面 | 商品の検索・一覧表示 | 一般会員／店舗管理者 | |
| F-O-006 | （例）商品登録画面 | 新規商品情報の入力・登録 | 店舗管理者 | |
| F-O-007 | （例）注文一覧画面 | 注文の検索・一覧表示 | 一般会員／店舗管理者／システム管理者 | アクターにより表示範囲が異なる |
| F-O-008 | （例）注文詳細画面 | 注文内容の詳細表示 | 一般会員／店舗管理者／システム管理者 | |
| F-O-009 | （例）注文登録画面 | 注文内容の入力・確定 | 一般会員 | |

## バッチ機能

| 機能ID | 機能名 | 概要 | アクター | 備考 |
|---|---|---|---|---|
| F-B-001 | （例）請求締めバッチ | 月次の請求データを締めて請求書作成システムへ連携 | システム（自動実行） | 月末日 23:00 実行 |
| F-B-002 | （例）売上集計バッチ | 日次の売上データを集計して会計システムへ仕訳データを送信 | システム（自動実行） | 毎日 2:00 実行 |
| F-B-003 | （例）マスタ同期バッチ | マスタ管理システムから顧客・商品データを取得して同期 | システム（自動実行） | 毎時 0 分実行 |
